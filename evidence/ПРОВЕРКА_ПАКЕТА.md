Первая Windows-проверка выявила отсутствие пустой папки data в свежем экспорте: один тест настройки не мог создать временный каталог. Добавлен только data/.gitkeep; база, кэш и рабочие настройки не включались. После исправления шесть проверок прошли. Первая Docker-попытка через прямой Linux socket не поддержала Windows bind paths; штатный Docker Desktop endpoint успешно запустил весь комплект. Это ошибки подготовки окружения, а не замаскированные успешные тесты.

После Windows-проверок временные локальные конфиги заменены переносимыми шаблонами. Доверие hooks в новом клоне должен лично подтвердить человек. Предыдущие реальные проверки рабочего сервиса и границы наблюдений описаны отдельно в ОТЧЁТ.md, СВЕРКА_20.md и run-report.json. Сохранённый HTML отражает полный прогон #21, а не живой склад на момент чтения.
