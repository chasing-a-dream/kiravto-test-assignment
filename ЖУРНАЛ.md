# Журнал разработки

Это сокращённый журнал технических решений и реальных проверок. Личные инструкции по подготовке видео исключены. Время указано только там, где оно зафиксировано; активное время и денежные расходы агента неизвестны. Восстановленная статистика токенов выбранных сессий приведена в evidence/ЗАТРАТЫ.md.

## 22 октября: постановка и первые проверки

Поставлена задача наблюдать склад РОЛЬФ Ясенево, сохранять историю, публиковать только после человека, предоставить API/MCP/LLM/HTML. Пользователь подготовил Docker, каналы, группу и секреты через скрытый ввод. Боевой режим не включался.

Скилл source-recon применён для исследования публичного источника и сверки. Браузер Microsoft Edge использовался для чтения карточек. Найдены структурированные RIS-ответы; извлечение бизнес-полей из вёрстки не принято основным способом. Сверка 20 карточек выявила цвет-код вместо названия и неверную трактовку «4 и более владельцев»; исправлены нормализация и кэш.

Скилл history-invariants применён к неполным прогонам, возврату и перевыставлению; снятие потребовало полного склада и отдельного статуса. Скилл moderated-outbox применён к долговечной очереди, отказу, повторным кнопкам и uncertain-результатам. Доказательства применения — соответствующий код, tests и сценарии ниже.

Первый технический пост прошёл группу и человеческую кнопку; затем отдельно согласованы карточка Camry и отрицательный пример. В живой группе подтверждены опубликованный пост, отклонённый пост и отсутствие дубля после повторной кнопки.

## 23 октября: полнота источника и надёжность

Независимые агенты исследовали источник и проверяли код в отдельных worktree/ветках; основной агент перепроверял diff, тесты и браузерную сверку. Вложенных агентов не использовали; тесты запускали максимум в двух потоках. Собственная браузерная сверка независимого агента не состоялась из-за ошибки CUA и не засчитана.

Прямой NEW-запрос оказался суженным скрытыми фильтрами. Реализовано перечисление ALL и USED через проверенные диапазоны скидочной цены, разбиение одинаковой цены по цветам, точные множества ID и повторная сверка. Полные #9/#10/#12 подтвердили склад; границы и метрики сохранены в evidence.

Реальная CLI проверила доверенные hooks: SessionStart выдал контекст, PreToolUse отказал на безопасном тесте включения production. Самого наличия файлов за доказательство не принимали. Перенос путей нового клона выполняет configure_agent.py.

Бесплатная LLM сначала вернула пустой обрезанный ответ. Исправлены бюджет итогового ответа, обработка null/невалидного JSON, сохранение usage и отсутствие слепого повтора. Независимый reviewer нашёл дополнительный крайний случай чисел/конвертации стоимости; исправлен и проверен. Реальная повторная проба на явно синтетическом описании вернула 3 точные цитаты; повтор обслужен из кэша. Реальные описания автомобилей модели не отправлялись. Успех cost0,151input/118output по провайдеру; первые неуспешные расходы неизвестны.

Неполные #13–15 показали ошибки JSON, транспортного запроса и фото. Реализован один обычный ограниченный по частоте повтор только для транспортного сбоя; типизированная ошибка позволяет сохранить здоровые карточки, но оставляет весь прогон неполным. Третий транспортный сбой останавливает обход; HTTP-отказы/капча/невалидный JSON не повторяются.

Контроль #16 встретил карточку со статусом REMOVED и пустой ценой в ранее перечисленной выдаче. Старую цену не подставляли. Минимальный реальный fixture и отрицательный тест подтверждают отказ. #17 прошёл полностью:418ID,173новых/245подержанных,563запроса,1560.86с. Независимое ревью source-transport в отдельной ветке/worktree не выявило существенных замечаний.

Исторические 124 теста: Windows7.749сOK, Docker2.510сOK,2Windows-проверки пропущены. Ошибки старого test image были пойманы до итогового результата; тесты Docker запускают текущие исходники readonly без сети и секретов.
