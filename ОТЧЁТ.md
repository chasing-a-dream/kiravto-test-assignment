

# Сделано

Сервис наблюдает РОЛЬФ Ясенево на Авто.ру. Реализованы публичный структурированный сбор, история обеих цен и контента, безопасное снятие/возврат/перевыставление, нормализация и аномалии, Telegram-очередь с человеческой модерацией, HTTP API, свой MCP, LLM-факты с точными цитатами, HTML-отчёт и метрики. Исходные наблюдения неизменяемы; настройки по умолчанию оставляют боевой режим, автоматические посты и LLM выключенными.

- Сверены 20 случайных реальных карточек в Microsoft Edge; seed и расхождения — СВЕРКА_20.md. Найденные ошибки цвета и категории владельцев исправлены. Повторная браузерная выборка 24 октября не выполнялась.
- Исторический полный комплект: 124 offline-теста на Windows за 7,749 с; Docker без сети — 124 за 2,510 с, 2 Windows-теста пропущены. Финальный тест экспортируемого пакета фиксируется отдельно в evidence/ПРОВЕРКА_ПАКЕТА.md.
- HTTP после #21: health/stock/offers/drops/runs/report/OpenAPI — 200, без токена stock — 401, неверная пагинация — 422; health=ok, stale=false на время проверки.
- Настоящий MCP SDK проверил все 7 инструментов; native MCP после #21 подтвердил полноту и историю снижений. Тесты MCP используют настоящий клиент.
- В Telegram проверены человеческое одобрение, отказ, повторная кнопка без дубля, перезапуск и ошибка сети через fake API/TCP. Camry #2 опубликована, #3 отклонён; BMW #4 опубликован 24 октября после отдельного согласия и кнопки, album IDs [6,7,8]. Содержательные публикации в разные календарные дни подтверждены. Основной канал не использовался.
- LLM: реальный записанный ответ бесплатной модели на синтетический ввод, 3 факта с точными цитатами, 151 input / 118 output токенов, cost=0 по провайдеру; повтор из кэша. Сохранён и реальный пустой обрезанный ответ. Невалидный результат считается failed, usage не теряется. Реальные описания не отправлялись.
- Реально использованы три проектных skills; независимые сверщики работали в отдельных ветках и worktree без вложенных агентов. Основной агент проверял diff и тесты. Два hooks лично подтверждены пользователем и проверены в настоящей CLI, включая безопасный отрицательный пример.

# Нашёл

- Склад меняется во время обхода. Полнота требует согласованных повторных множеств; сетевой сбой, противоречивый статус, неверный JSON или невалидное изображение оставляют прогон неполным и не снимают объявления.
- 23 октября неполные #13–16 выявили разные проблемы: невалидный JSON, транспортный обрыв, фото и уже снятую карточку в выдаче. 24 октября #19/#20 отражали сбой сетевого маршрута Docker. Успешный #21 получен после восстановления маршрута пользователем; защита не ослаблялась.
- source_updated_at может массово меняться. Полный #21 потребовал 416 карточек заново; экономию кэша нельзя обещать на каждом запуске.
- with_discount=true относится к цене после максимальных скидок. Основная цена, скидочная цена и условия не смешиваются. Точное перечисление одинаковых цен потребовало проверенного разбиения по цветам.
- Постоянно декодируется только первый оригинал каждой машины. Для опубликованного BMW три оригинала проверены отдельно; общая проверка всех файлов склада не заявляется. Фото больше 10 МБ может оставить Telegram-пост failed.
- История началась 22 октября, полной недели нет. 29 событий снижения >=5% относятся к 23 уникальным объявлениям (15 основной и 14 скидочной цены). События не гарантируют текущую выгодность автомобиля.
- Неизвестный результат отправки Telegram остаётся uncertain без слепого повтора. На тестовом ПК Telegram требует локального TLS-помощника, описанного в README; на иной сети может работать напрямую.
- Общие время, токены и стоимость разработки точно не измерены. Стоимость успешной LLM-пробы 0 по провайдеру; старые неудачные попытки сохраняют неизвестные расходы/резервы. Автоматические LLM-вызовы выключены.
- Дополнительные задания со звёздочкой не реализованы. Видео пока не записано, поэтому полная сдача не объявляется завершённой.
